# Harvest Web Studio images

Place the following generated WebP images in this directory:

- `hero-consultation.webp` — recommended 1600×1200, ideally 300 KB or less
- `work-salon.webp` — recommended 1600×900, ideally 200 KB or less
- `work-legal-office.webp` — recommended 1600×900, ideally 200 KB or less

Until each file is present, the landing page automatically displays its existing
local CSS mockup. No external image URL is used.
