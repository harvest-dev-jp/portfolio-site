リタイアメント・シミュレーター

資産形成から引退後のキャッシュフローまでを見通すシミュレーションアプリ。

Next.js / TypeScript / SVGグラフ

プロジェクト概要

このプロジェクトは、リタイア後の資産寿命を予測するためのシミュレーターです。
現在資産、生活費、年金、投資リターン、インフレ率などの条件を設定し、将来の資産推移を1か月単位で試算できます。
想定寿命時点の資産残高を確認することで、生活費や積立額の見直しに役立てることができます。

主な特徴

  • 1か月単位の資産推移シミュレーション
  • リタイア年齢・寿命・年金条件を自由に設定
  • インフレを考慮した生活費シミュレーション
  • 資産寿命をグラフで可視化

ユーザーへの価値

将来の資産推移を理解し、不確実な市場環境でも安心して資産設計できるように支援します。
個人のライフプランニングや退職計画に最適です。

診断コメント

想定寿命90歳時点では714万円の資産が残る見込みです。ただし91.4歳で資産が枯渇するため、長寿リスクに備える場合は生活費の見直しが有効です。

改善提案

100歳まで資産を維持するには、 年間生活費を390万円程度に抑える必要があります。

現在より年間40万円の削減が目安です。

積立額の増加だけで解決するには、年間460万円の追加積立が必要です。

現実的には、生活費の見直しやリタイア年齢の再検討もあわせて検討してください。

または、リタイア年齢を70歳まで延ばすことで、 資産維持を目指せます。

※このシミュレーションは概算です。税金、社会保険料、手数料、相場変動などは考慮していません。
